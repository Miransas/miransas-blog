Animation is what separates a static page from a delightful experience. Done well, motion guides attention, communicates state, and adds personality.

## Principles of good motion

Before reaching for a library, keep these in mind:

- **Purposeful** — every animation should have a reason
- **Fast** — most UI transitions should be under 300ms
- **Interruptible** — users should never feel blocked

## Our favorite libraries

### Framer Motion

The gold standard for React animation. Declarative, powerful, and surprisingly easy to pick up.

### React Spring

Physics-based animations that feel natural and fluid.

### Auto-Animate

Add smooth transitions with a single line of code — perfect for lists and layout changes.

> Subtle motion beats flashy motion every time. Restraint is a feature.

## Conclusion

Start with one library, master the basics, and layer in complexity only when it serves the user.
