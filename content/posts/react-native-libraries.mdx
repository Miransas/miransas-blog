React Native lets you build native mobile apps with the React skills you already have. The ecosystem of libraries makes it possible to ship polished apps quickly.

## Must-have categories

- **Navigation** — moving between screens
- **State management** — keeping data in sync
- **UI components** — buttons, lists, and more
- **Animations** — smooth, native-feeling motion

## Standout libraries

### React Navigation

The de facto standard for routing in React Native apps.

### Reanimated

Run animations on the native thread for buttery 60fps performance.

### Expo

A toolchain that removes most of the pain from building and shipping React Native apps.

## Conclusion

The React Native ecosystem is mature and productive. Pick the right tools and you can ship cross-platform apps faster than ever.
